# 🦾 Lannister News / Stark Advisor

Plataforma académica y de desarrollo orientada al análisis financiero, suscripciones de usuarios y un ChatBot inteligente.  
El proyecto combina **Node.js + Express** para el backend, **Python ** para el ChatBot con (BERT/RoBERTa), y bases de datos **MySQL** y **MongoDB** para el almacenamiento revisar backend.
